# MEMI輕音 v1.22

> 相对 v1.21 的增量版本：**换了一套图标**，并把冷启动那张“只有一个图标”的图改成了带应用名的一页。
> 播放、歌词、设置页的逻辑一律没动，升级后功能与 v1.21 完全一致。

## 图标：从一张母版重出全套

之前那套图标是历代手改留下的，各档尺寸的取景并不一致。这版把母版统一到 `icon/src/memi_icon_master.png`（1024×1024，构图含「輕音」「MEMI」「MUSIC PLAYER」），一次生成 13 个资源：

| 资源 | 规格 |
| :--- | :--- |
| `mipmap-*/ic_launcher.webp` | 48 / 72 / 96 / 144 / 192 五档，圆角方形，圆角半径 21.5%，四周留 3% 黑边 |
| `mipmap-*/ic_launcher_round.webp` | 同上五档，圆形遮罩 |
| `ic_launcher_foreground_material.png` | 自适应图标前景，1024 画布，图案落在 72/108 安全区 |
| `ic_launcher_monochrome_material.png` | 主题图标（Android 13+ 随壁纸上色），按亮度取 alpha 并做 0.6px 羽化 |
| `ic_memi_splash.png` | 启动图，512 圆形，保持 RGBA 避免边缘白边 |

另外新增 `icon/make_app_icons.py`：换图标只需要替换母版再跑一次脚本，不用再手改十几个文件。

## 冷启动：从“一个图标”变成“图标 + 应用名”

Android 12 之后的系统启动图只能配背景色和图标，**放不下文字**。所以这版拆成两部分：

- 系统那张图只保留底色（图标改成全透明），深浅色各自和后面一页同色；
- 紧接着的一帧是自绘的品牌页：同样的底色、同尺寸的圆形图标，下面挂应用名 `MEMI輕音`。

| | 之前 | 现在 |
| :--- | :--- | :--- |
| 深色启动底色 | `#121212` | `#000000` |
| 浅色启动底色 | `#FFFFFF` | `#FFFFFF`（不变） |
| 启动画面 | 只有一个图标，随后跳一次 | 底色 → 图标与应用名一起出现 |
| 状态栏图标 | 白底上仍是白色，几乎看不见 | 跟随深浅色切换 |

细节：

- 品牌页最短停留 350ms；内容加载更慢就继续停留，沿用原来的转圈指示，不额外拖时间。
- 图标与应用名从 95% 透明度淡入 180ms，出现得不那么硬。
- 只有真正的冷启动会出现；旋转屏幕、从后台切回来都不会再插一页。
- 首次安装会直接进免责声明，品牌页不会挡在前面。


## 已知限制

- 仅提供 `arm64-v8a`，32 位设备与模拟器需自行从源码构建。
- 系统启动图的图标已置空，部分厂商 ROM 会在这一帧叠加自己的加载动画，属系统行为，应用侧无法干预。
- 图标母版里「MUSIC PLAYER」这行字在 48dp 下已不可辨，属正常缩放损耗。
- 设置页仍有历史遗留：7 套自建卡片壳尚未合并、部分圆角常量仍分散在各文件。只影响代码整洁度，不影响功能。
