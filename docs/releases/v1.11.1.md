# MEMI輕音 v1.11.1

> 首次公开发布。当前版本号 v1.11.1，本文列出的是**相对上游 NeriPlayer 的全部改动**，不是版本间的增量差异。

基于 [NeriPlayer](https://github.com/cwuom/NeriPlayer) 的第三方修改版。保留原项目的播放内核、多平台音源、歌词解析与本地管理能力，重做了界面层与播放页交互，并新增分档性能控制。

支持 Android 9（API 28）及以上，原生 Compose 实现，独立包名可与原版并存安装。

## 界面：全面接入 Mochi UI

| 改动 | 范围 |
| :--- | :--- |
| 主题桥接 | 新建 Material ColorScheme → Mochi 色彩桥接层，全应用 Mochi 组件跟随主题 |
| 全局轮廓 | 形状体系全档位换成连续曲率圆角，Material 组件轮廓统一 |
| 底栏 | 底部导航换 Mochi 标签栏 |
| 设置页控件 | 开关 / 复选框 / 滑块 / 分段控件统一换 Mochi，覆盖 **98 个设置文件** |
| 对话框与面板 | 统一对话框换连续圆角（32 个文件共用）；16 处底部面板换 Mochi 圆角与胶囊把手 |
| 顶栏 | 新建中间层包裹顶栏，只替换标题字阶，保留折叠行为、insets 与预测性返回；**24 个文件 38 处**已迁移 |
| 迷你播放器 | 形状换连续圆角，进场/退场改用弹簧动画 |
| 初次设置 | 开关 / 滑块 / 单选 / 分段 / 进度条全部 Mochi 化，自绘弹性单选圆点与胶囊进度条 |
| 交互反馈 | 6 类按钮原语统一加入按压回弹（放大而非缩小，幅度随尺寸递减），**覆盖 52 个文件**；播放/暂停图标切换与迷你播放器进出场改弹簧曲线 |

修复了两类实际问题：

- **开关「看着是 Mochi 但没手感」**：3 处开关传了空回调，导致内部手势整段跳过，已改为真实回调；另修复一处固定尺寸容器把开关轨道压窄、拇指行程只剩 14dp 的问题
- **启动阶段弹窗白底**：深色模式下初次设置与免责声明的 Mochi 组件落回库默认浅色，已补齐色彩桥接

## 播放页

- **长条屏留白**：封面尺寸原先只跟宽度挂钩，20:9 屏幕多出的高度全变留白。改为按窗口长宽比在 16:9 → 20:9 之间把宽度占比从 60% 线性提到 74%（超长屏封顶），16:9 完全保持原样
- **手机横屏**：新增左右分栏布局，封面与歌词并排
- **横屏安全区**：状态栏与挖孔（含左挖孔）不再推挤内容
- **三处滑块**：扬声器音量、歌词偏移、歌词字号统一换 Mochi 滑块
- **进度条手势**：移除单击跳转（避免误触），改为相对拖动
- **波浪可关**：新增设置项，可关闭进度条的波形绘制

## 歌词

- **行对齐**：新增「跟随 / 居中」选项。逐字歌词是 Canvas 自绘而非文本组件，对齐通过一个 0–1 的位置系数贯穿排版、缩放原点、译文与呼吸点四处；普通行可居中，**对唱行仍保留左右分列**（避免两句叠在屏幕中间）。默认「跟随」保证升级后画面不变
- **自动断行**：加入避头点 / 避尾点规则，长句不再在标点处断得难看
- **点击二次确认**：第一次点击先高亮目标行，再点一次才跳转，避免滚动歌词时误触
- **手动浏览**：手指拖动浏览歌词时整屏保持清晰，不再施加背景模糊；松手回滚时各行同步到位，不会再出现当前行先归位、其它行慢半拍的错位感

## 显示与适配

- **深色模式**：修复桌面长按菜单里快捷方式图标在深色下纯黑不可见；修正主题取色未跟随手动深浅色设置的问题
- **平板**：平板设备自动锁定横屏，按大屏布局呈现
- **底栏毛玻璃**：底部栏接入与顶栏一致的实时玻璃模糊
- **下线「简洁」界面风格**：相关设置卡片、启动询问弹窗与液态玻璃开关一并移除，旧备份中的 `clean` 值自动回落为默认风格，不会崩溃

## 性能与功耗

新增**性能模式**三档，入口：**设置 → 动效设置 → 动效总开关 → 性能模式**。

| 档位 | 动态背景帧率 | 玻璃模糊 | 歌词模糊 |
| :--- | :--- | :--- | :--- |
| 画质 / Quality | 60 fps | 跟随用户设置 | 跟随用户设置 |
| 均衡 / Balanced | 30 fps | 超低（region-local 降采样） | 减半 |
| 省电 / Power saving | 20 fps | 超低（region-local 降采样） | 关闭 |

- 降级针对逐帧重绘的主要开销：音频可视化动态背景、歌词模糊的逐帧插值、玻璃模糊的背景采样
- **不改变**用户单独设置的各特效开关，只在所选档位内统一降级
- 切换即时生效，无需重启

## 安装

1. 下载上表的 APK
2. 允许「安装未知来源应用」
3. 安装并启动，首次会显示免责声明并进入引导流程

> 当前只提供 `arm64-v8a`。32 位设备或 x86 模拟器请从源码构建，加 `-PbuildAllReleaseAbis=true` 可产出多 ABI 包。

## 已知限制

- 自建音乐服务器（Navidrome / OpenSubsonic）为预览能力，兼容性随服务器与网络环境而异
- 开启 32-bit 高解析输出时，响度均衡、声道平衡、音频可视化与应用内倍速会被旁路
- 蓝牙车载歌词借用曲目标题区域实现，刷新率取决于手机与车机
- 「简洁」界面风格已下线，旧主题设置会自动回落为默认风格
- 省电档关闭歌词模糊后，非当前行的淡出仅依靠透明度
