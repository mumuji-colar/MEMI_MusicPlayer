**MEMI輕音 v1.21｜歌词不再把词劈开，底栏也和播放条对齐了**

这版两件事：一件是歌词断行，一件是底栏宽度。

**① 歌词：不在词中间换行了**

以前的换行逻辑只会算「哪一行最整齐」。中文没有空格，一整句在排版眼里就是一个特别长的词，所以字和字之间完全平等——最整齐的位置经常正好落在词的中间：

「我想要和你一 / 起去看海」

「一起」就这么被劈了。避头点只能管标点，管不了词。

现在换行前会先查一下系统内置的中文词典，判断这里是不是词和词之间。如果非要在词内部断，得付一笔固定的代价：大约等于「宁可多空出 5 个字」。所以只要词边界附近能放得下，就会优先断在词边界上。

顺带修了两个标点毛病：

· 「——」「……」不会被拆成两行、各留一半
· 左引号「“」不留在行尾

逐字卡拉 OK 版和整行版两套渲染都改了，不会出现「一个模式修了另一个没修」。

**② 底栏与播放条对齐（默认开）**

之前底栏是「左右留 20dp + 按内容收窄」，上方的播放条是「左右留 8dp + 占满宽度」，两条叠在一起边缘差一截，像没对齐的积木。

现在底栏的留白收到和播放条一样的 8dp，并把可用宽度均分给四个格子，胶囊正好铺满——两条栏同宽、左右边线重合，竖着看是一条列。

不习惯的话可以关：设置 → 界面布局 → 播放 → 播放页控制 → 底栏与播放条对齐。关掉就回到原来的样子。

（Clean 风格底栏本来就是满宽齐边的，这个开关对它不做事。）
