# MEMI輕音 v1.22.1

> 修 bug 的版本，没有新功能。三件事：歌单初始化不再被判死刑、播放页封面不再被降画质。

## 修复：本地歌单可能永久不可用

有些设备上「本地歌单」页会一直显示「本地歌单初始化失败，请重启应用后重试」，而且重启确实不管用——新建歌单、扫描导入全部失效，只能清数据重装。

原因在初始化流程里有两处直接抛异常：

| 场景 | 之前 | 现在 |
| :--- | :--- | :--- |
| 旧歌单文件读不出来 | `throw IOException` | 退到备份；备份也没有就用空库启动 |
| 旧存储无法校验 Room 迁移 | `throw IOException` | 关掉迁移，继续以 JSON 为准 |

这是一个设计问题而不只是某台机器的问题：一次坏文件就把整个歌单功能锁死，重试走同一段代码，自然不会好。现在最坏情况是「歌单空了但能马上重新导入」，而不是功能整个报废。

如果你之前遇到过这个提示，升级后不会再出现；已经坏掉的数据仍然建议清一次应用数据重新导入。

## 修复：播放页封面发糊

网易云等平台给的封面地址带尺寸参数（`?param=300y300`），而播放页解码时又有一道 512px 的上限，两道限制叠在一起，1080p 屏幕上放大必然模糊。

- 地址：网易云 `?param=NyN` → `1080y1080`，QQ 音乐 `T002R300x300` → `T002R1200x1200`；
- 解码：播放页上限 512 → **1280**，迷你播放条仍保持 512 省内存。

播放页大图和后面的模糊背景都走同一个地址，不会重复下载。

> 升级后如果仍显示旧图，进「设置 → 存储概览 → 缓存」清一次封面缓存再看。
