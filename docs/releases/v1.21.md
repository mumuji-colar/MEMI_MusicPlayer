# MEMI輕音 v1.21

> 相对 v1.20 的增量版本：**歌词按词断行**，外加一个把底栏和播放条拉齐的开关。
> 设置页重构、Mochi UI、性能模式等完整改动见 [v1.20 说明](./v1.20.md) 与 [v1.11.1 说明](./v1.11.1.md)。

## 歌词：不再从词中间劈开

以前中文歌词的断行是「哪里最整齐就断哪里」：中文没有空格，一整句在排版眼里是一个超长单词，字与字之间完全等权。于是最整齐的位置经常正好落在一个词的中间：

```
我想要和你一
起去看海
```

这一版先问一句「这里是不是词与词之间」，再决定在哪断。

| 改动 | 做法 |
| :--- | :--- |
| 词边界 | 用系统自带的 ICU 中文词典（`BreakIterator`）标出词边界，不额外下载词库 |
| 拆词的代价 | 断在词内部 = 固定加项 `5.0 × 平均字宽²`，约等于「宁可多空出 5 个字」 |
| 词边界 | 不再额外打折（×1.0），优势全部交给上面的惩罚，避免两个系数互相抵消 |
| 作用范围 | 只作用于「汉字 + 汉字 + 词内」；拉丁词本来就整词禁断，标点走避头避尾，假名/谚文不套中文词典 |
| 两套渲染器 | 逐字卡拉 OK 版（自算断点）与整行版（Compose 文本断行）都接上了，不再只修一半 |

拆词惩罚特意做成**与剩余宽度无关的加项**，而不是乘在系数上：行填得越满，剩余宽度越接近 0，任何乘数都会被抹平——而「填得满」恰恰是最容易拆词的时候。

顺带修了两处标点问题：

- 「——」「……」不会再被拆成两行、各留一半；
- 左引号「“」不再留在行尾。

## 新增：底栏与播放条对齐（默认开启）

浮起样式的标签栏原来是「左右留白 20dp + 按内容收窄」，上方的迷你播放条是「左右留白 8dp + 占满宽度」，两条栏叠在一起边缘差了一截，看着像没对齐的积木。

打开这个选项后：

| | 之前 | 现在 |
| :--- | :--- | :--- |
| 底栏左右留白 | 20dp | 8dp（与播放条同一个值） |
| 底栏宽度 | 按 4 格的固定格宽收窄 | 按可用宽度均分格宽，胶囊铺满 |
| 两条栏关系 | 宽度不等、边缘错开 | 同宽、左右边线重合 |

位置：**设置 → 界面布局 → 播放 → 播放页控制 → 底栏与播放条对齐**。

关掉即恢复旧样子。Clean 风格底栏本来就是 16dp 满宽、与同风格播放条齐边，这个开关对它是空操作。


## 已知限制

- 仅提供 `arm64-v8a`，32 位设备与模拟器需自行从源码构建。
- 词边界来自 ICU 词典：人名、生造词、中英混排的怪写法偶尔会被切错，属词典本身的边界，不为此塞自定义词库。
- 整行模式优先使用系统的按词断行策略，低版本系统上会退回系统默认断行——不会变差，只是拿不到词级优化。
- 设置页仍有历史遗留：7 套自建卡片壳尚未合并、部分圆角常量仍分散在各文件（语义不同，未强行归一）。这些只影响代码整洁度，不影响功能。
