# MEMI輕音 v1.20

> 相对 v1.11.1 的增量版本：**设置页重构完成**。首次公开发布以来的完整改动清单（Mochi UI、播放页、歌词、性能模式、品牌与合规）见 [v1.11.1 说明](./v1.11.1.md)，本篇只讲这次动过什么。

设置页过去是 8 张分组卡、22 个一级入口，同类功能被拆成平级页（音质 / 音效、主题 / 背景 / 个性化 / 动效、网络 / 流量管理），长尾功能（USB 独占、播放源）与常用项并排，一屏放不下也猜不到点进去是什么。

这一版把它收敛成 **4 张卡、11 个入口**，入口层级以两层为主，搜索栏改为按需出现。

## 设置页：22 个入口 → 11 个

| 卡片 | 入口 |
| :--- | :--- |
| 第一组 | 账号与音源、播放、歌词 |
| 第二组 | 外观、动效与性能、界面布局 |
| 第三组 | 存储与下载、网络与流量、备份与同步 |
| 第四组 | 通用、关于 |

合并方式不是简单地把页面叠在一起：原来的 22 个一级页面里，19 个变成「分类页里的卡片组」，音效与 USB 独占下沉为三级页，「关于」仍是独立入口；加上原本就独立成页的 3 个，现在共 5 个三级页：

| 三级页 | 位置 | 保留原因 |
| :--- | :--- | :--- |
| 音效 | 播放 → 高级音频 | 8 页签的动态编辑器，不是开关集合 |
| USB 独占 | 播放 → 高级音频 | 依赖外接 DAC，配置项密集 |
| 音乐服务器 | 账号与音源 | 服务器增删改查 |
| 存储概览 | 存储与下载 | 分类统计明细多 |
| 小米超级岛 | 歌词 | 依赖 Root / Shizuku，独立成页便于提示风险 |

> 「音效」和「USB 独占」这两个入口在早期版本里漏掉了，只能靠搜索进入，这一版补回到「播放 → 高级音频」。

## 搜索栏：不再常驻

顶部原来固定占着一行搜索框，进设置页第一眼就是它。现在改成：

| 状态 | 表现 |
| :--- | :--- |
| 刚进设置页 | 只有「设置」标题，无搜索框 |
| 向下滚动、大标题折叠后 | 搜索框从标题下方滑出 |
| 向上滚回顶部 | 搜索框收起 |
| 搜索词非空 | 输入框保留，并把列表拉回顶部 |
| 进入二级页 | 不出现（只在一级主页） |

内容不足一屏、或已经滑到底时会直接显示搜索框——否则大标题收不起来，入口就永远出不来了。

## 页内打磨

| 改动 | 内容 |
| :--- | :--- |
| **播放页减卡** | 「交叉淡入淡出」并入「淡入淡出」卡（分区线分隔），该页 4 卡 → 3 卡 |
| **外观页减卡** | 「色彩空间」原本独占一张卡且只有 1 项，并入「色彩风格」卡 |
| **流量管理重做** | 两张原生 Material3 卡片（大卡套小卡）改为卡内分区，与其余页面统一 |
| **补标题** | USB 独占首卡、下载首卡原本没有分区标题，已补齐 |
| **搜索落点** | 卡片合并后，搜索锚点全部重算，落在目标所在的卡片上 |

## 修复

- **分类页聚合崩溃**：早期版本把多个页面拼成一页时，卡片列表的 key 由运行时页面名生成，导致同页 key 重复直接崩溃；已改为各页固定 key，并新增静态断言守住。
- **三级页无入口**：上述「音效 / USB 独占」只能搜索进入；已补回入口，并新增「每个三级页必须有跳转语句」的测试。
- **主页高亮落空**：搜索直接跳到原子页（如「存储」「播放」）时，主页一个入口都不高亮；现在会向上找到所属分类。

## 安装

签名与上一版一致，可直接覆盖安装，无需卸载、不会丢设置：

```
adb install -r MEMI-1.20-2611201.apk
```

## 已知限制

- 仅提供 `arm64-v8a`，32 位设备与模拟器需自行从源码构建。
- 设置页仍有历史遗留：7 套自建卡片壳尚未合并、部分圆角常量仍分散在各文件（语义不同，未强行归一）。这些只影响代码整洁度，不影响功能。
